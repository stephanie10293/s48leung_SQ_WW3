
# Dream Duel


## Setup and Interaction Instructions

**Player 1**
- Move: A / D  
- Attack: F  
- Block: G  

**Player 2**
- Move: Arrow Keys  
- Attack: K  
- Block: L  

Press **ENTER** to start the game and again to play another round.
