# Dream Duel

## Setup and Interaction Instructions

### Player 1
- Move: A / D
- Attack: F
- Block: G
- Special Attack: R

### Player 2
- Move: Arrow Keys
- Attack: K
- Block: L
- Special Attack: O

### Objective
Reduce your opponent's health to 0 before the timer runs out.

### Gameplay Features
- Health Bar System (5 HP per player)
- Blocking System
- Special Attack with Cooldown
- 60-Second Round Timer
- Dream Orb Collectible that restores health
- Win and Draw Conditions
- Sound Effects and Background Music

Press **ENTER** to start the game and again to play another round.

---

## Remix Features

This project remixes the original fighting game by introducing several new gameplay systems:

### 1. Round Timer
A 60-second timer counts down during each match. When time runs out, the player with the most remaining health wins. If both players have the same health, the game ends in a draw.

### 2. Special Attack
Each player has access to a powerful special attack:
- Player 1: **R**
- Player 2: **O**

The special attack deals extra damage but has a cooldown, encouraging strategic use.

### 3. Dream Orb Collectible
A magical Dream Orb appears in the arena. When collected, it restores 1 health point and respawns at a new location, encouraging players to move around the stage and compete for resources.
